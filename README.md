# Cursor Landing Page – Recreation

A recreation of the [Cursor](https://dev-tool-landing-page.netlify.app/) landing page built using only HTML and CSS.

---

## Live Demo

https://dev-tool-landing-page.netlify.app/

---

## What I Built

I recreated all 11 sections of the original Cursor website:

1. **Navigation Bar** – Logo, links (Feature, Enterprise, Pricing, Resources), Sign In and Download buttons
2. **Hero Section** – Big headline, description text, Download button, and a large screenshot of the product
3. **Trusted By** – A row of company logos with the "Trusted by millions of developers" tagline
4. **Feature Sections** – 3 blocks, each with a screenshot on one side and text on the other (sides alternate)
5. **Feature Cards** – "Stay on the frontier" section with 3 cards covering models, codebase search, and enterprise
6. **Testimonials** – Quote cards from 6 people including Jensen Huang, Andrej Karpathy, and Patrick Collison
7. **Recent Highlights** – 3 blog/post cards with title, category, and date
8. **Changelog** – A short list of updates with version numbers and dates
9. **Team Section** – A team photo with a short description and a "join us" link
10. **Final CTA** – A big "Try Cursor Now" heading with a Download button
11. **Footer** – 5 columns of links (Product, Resources, Company, Legal, Connect) plus copyright info

---

## Rules Followed

- Only HTML and CSS — no JavaScript
- No Tailwind or any CSS framework
- No animations
- Desktop layout only — no mobile responsiveness
- Images and icons matched to the original site where possible
